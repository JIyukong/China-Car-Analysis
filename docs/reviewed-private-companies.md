# 已核实非上市经营主体建档

`python -m scheduler.runner --seed-reviewed-private-companies REPORT_JSON --plan`
离线列出固定核验清单；去掉 `--plan` 后通过独立 ETL 账号与仓库锁执行增量更新。

本清单按数据字典的非上市公司规则登记合创、合众、威马的独立经营法人，
`company_type='其他'`、`is_listed=0`，不将全部销量归入参股上市公司。
它不判断最新股东持股比例，不注册证券，不提供投资结论，也不推断复杂收购的历史生效期。

依据保存在 `scheduler/reviewed_private_companies.py`：广汽2023年报确认合创的名称延续及25%持股，
亿华通2026年监管问询回复确认合众主体，最高人民法院公告确认威马集团主体。
同名、编码或全称存在冲突即拒绝覆盖；只更新已有主机厂，复用既有归属和品牌桥接校验。
全部公司与主机厂变更在同一事务中，任一失败整体回滚，提交后才生成回执。

命令不发送飞书消息，不直接改写已发布事实或汇总。根据回执给出的全国月份，
仅对来源已验收、等待补维的批次运行统一入口的 `--resume`，仍执行来源版本回读和完整发布验收。
未确认归属、DS等需要分期的收购记录，以及来源失败的月份不在此清单中。
