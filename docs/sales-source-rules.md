# 全国销量来源检查规则

用户于2026-11-27确认以下范围明确的规则（reviewed_sales_v1），仅用于全国 style，不扩展到城市链。

- 车型名或厂商名为空/NaN/None/null/N/A：按网站脏数据排除，不计入有效销量；保留原始CSV及排除原因。
- 一汽红旗/红旗H5：保留来源车型编号127847，将129643列为疑难数据、不计入正常销量。
  2026-11-27来源核对：[127847历史](https://xl.16888.com/s/127847/)显示102条月度记录，
  [129643历史](https://xl.16888.com/s/129643/)仅10条。不是按销量大小选H5，也不按价格猜身份；同名冲突缺编号需重新抓取。
- 比亚迪/秦新能源同月多条：保留销量最大记录，较低记录留在疑难明细，不相加。
  并列最大仍进入重复校验，不用这条规则掩盖分页重复。
- 其他重复：继续校验并局部重抓最多两轮、每轮最多六页。仍重复则记录具体数据，不假定去重后整月完整。
  对跨页漂移，仅当全部实测正数来源ID恰好覆盖网站总条数、每个ID的内容一致且业务键检查通过时，
  允许用已观察到的完整ID集合恢复分页。缺一个、多一个、内容冲突、无ID或城市链均不得这样恢复。
  每次重抓的页码、原行及恢复方法保存在 page_retry.json。

原始CSV SHA256及全部分页行数仍必须与网站总数相符；有效行数+排除行数=原始行数。
有效业务键仍须唯一，销量等字段仍须合法；不能因为有排除规则就接受漏页、跨月或全部为空的月份。
排除明细保存为原CSV同名的 `.review.json`，包含规则版本、原始哈希、原始/有效行数和被排除原行。
ODS/DWD已有历史缺键保护继续有效，不删除或清空正式表。若已有旧版本与新口径冲突，单独核实，不能自动删除历史。
