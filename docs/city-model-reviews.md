# 城市车型审核清单与应用

审核清单 `data/manual_dimensions/city_model_reviews.json` 随代码提交，包含原有57项和2026-11-28核准的286项；每项保留九字段及来源链接。清单只针对独立 `dim_city_model`。

名称明确含“海外”或“进口”的27项，按用户授权使用 `OEM_OVERSEAS_OUT_OF_RESEARCH` / `海外主机厂不在研究范围内`；这是研究范围汇总分类，实际主机厂线索保留在 evidence 中。未带这些标记的进口车型仍维护其实际主机厂分类。公司层面沿用既有 `OUT_OF_RESEARCH`，城市车型不依赖 company_code。

普通油混和48V轻混归燃油，插混、增程、纯电归新能源。跑车、微面、轻客映射仓库“其他”大类。汽油/CNG等混合来源的能源归“其他”。进口渠道不能仅从车型名确认时保持合法值 `unknown`。上汽大通MAXUS为来源提供的品牌聚合名，不猜填具体车型。

离线检查：

```powershell
python -m scheduler.runner --apply-city-model-reviews logs/etl/city-model-review-receipt.json --plan
python -m scheduler.runner --plan
python -m pytest
```

需要在其他已部署环境应用时，使用独立ETL账号，去掉第一条的 `--plan`。本次工作环境已完成应用，无需再次执行。命令按来源车型业务键增量更新；已确认且不同于清单的记录拒绝覆盖，缺少档案的记录列在 absent 中。

应用持有仓库锁，在同一数据库事务回读九字段，并核对城市和全国DWD各自的行数、销量总量。它不创建表、不更新销量事实、不发送消息。提交后保存回执并刷新本地 city_model_gaps 与状态摘要；回执或摘要失败不表示数据库已回滚，应先查看错误及现有回执。若回执写入失败，队列可能仍是旧快照；换用可写的回执路径重复执行即可回读确认并刷新队列，不会重复更新已确认记录。
