## 四、当前真实运行链路

### 4.1 冷启动链路

```text
手工执行 DDL
    -> Python 依赖安装
    -> 配置 .env
    -> scripts/init_database.py --skip-ddl --with-dwd
       -> seed_dim_date
       -> seed_dim_company_stock
       -> seed_dim_index
       -> seed_dim_commodity
       -> seed_dim_oem_brand
       -> seed_dim_from_excel
       -> load_16888_style_to_ods
       -> load_16888_city_to_ods
       -> build_sales_dimensions
       -> clean_sales_dwd
       -> update_lifecycle
```

补充说明：

- `04_create_dws_tables.sql` 当前不在 `init_database.py` 执行链中，需要手工执行
- `02_create_powerbi_user.sql` 当前不在 `init_database.py` 执行链中，需要手工执行
- `06_alter_dim_model_add_brand_oem_ads_columns.sql` 属于存量兼容补丁，不是新库初始化主链必跑项

### 4.2 调度链路

`runner.py` 遍历 `task_config.py` 注册全部任务，包含三条独立链路：

**style 月链**（每月 12-15 号 03:00 探测，未发布则 SkipTask）：

```text
crawl_16888_style_monthly
    -> load_style_ods
    -> build_sales_dimensions
    -> refresh_ads_zipper
    -> run_dwd_clean
       -> update_lifecycle（并行）
       -> run_dws_agg（并行）
```

**city 月链**（每月 20-25 号 03:30 探测）：

```text
crawl_16888_city_monthly
    -> load_city_ods
    -> run_dwd_city_clean
```

**日链**（交易日守卫，mon-fri）：

```text
17:30  load_stock_daily       # A 股/H 股日线
17:30  load_futures_daily     # 商品期货主力连续
17:45  load_index_daily       # 同花顺行业指数
18:30  load_stock_finance     # A 股财务
```

当前调度状态：

- 所有任务均已在 `task_config.py` 注册并由 `runner.py` 自动加载
- `build_sales_dimensions`、`agg_sales_monthly`（run_dws_agg）、城市 DWD 清洗均已接入调度
- 股价/指数/期货/财务采集任务均已接入调度
- 待验证项：生产环境连续运行稳定性、告警链路、数据质量校验自动化

- 一个里程碑对应一次提交

- 提交后回写本大纲中的状态表

遵循 Conventional Commits：
