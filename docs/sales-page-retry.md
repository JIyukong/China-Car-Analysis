# 销量异常页局部重抓

全国 2026-07 页 10/11 的同销量边界重复在定向请求中发生变化：标致508（109528）与菱智新能源（128231）均曾重复，销量均为62。这支持分页排序不稳定的判断，不能仅凭重复消失证明整月完整。源站厂商明细可交叉核对单个车型，不能替代全国覆盖验收。

采集完整榜单后，仅对内容一致的重复业务键涉及页进行最多两轮替换，每轮最多六页，沿用采集限速。校验月份、页码、分页状态、来源总数和页行数；候选整月唯一键数必须等于来源总数。内容冲突、持续重复、范围过大或元数据变化直接失败。不累积重试结果、不累加销量、不修改历史排名。

只在发生重复时保留 `page_retry.json`（至多六页原记录）。不新增逐页 HTML 存储。现有请求失败时保留异常 HTML 的行为不变。原有 CSV 字段、manifest、ODS 对账与发布验收保持兼容；CSV 哈希在替换完成后重新生成。

`python -X utf8 -m scripts.sales_source_probe 2026-07 10 11` 可独立诊断指定全国页面，无数据库依赖、不写 HTML。输出始终标记不可据此发布，避免把局部检查当整月验收。

合并部署后先验收一个异常月份，确认来源覆盖、ODS 增量回读及发布结果，再逐步处理历史周期。此补丁不解决城市历史缺键或人工归属缺项，不改变数据库结构。离线测试通过不表示生产月份已验收。

代价：采集过程额外保留当前月份记录于内存；只有重复时增加有限网络请求。局部替换不能提供源站事务快照保证，仍依赖来源总数及下游完整验收；来源持续不稳定时保留待处理，不追加无限重试或按月份特例。
