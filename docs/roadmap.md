# 项目路线图

## 目标与范围

为汽车行业投资者和分析师提供可追溯的销量、行情和财务数据，支持用 Power BI 开展描述性分析与销量、股价关联研究。数据开发者可复用数仓模型和采集链路。项目以数据交付为主，FastAPI 提供健康检查。自研前端、业务查询 API 和美股采集目前均在范围之外。

## 里程碑

| 阶段 | 仓库现状 | 下一步验收 |
| --- | --- | --- |
| M0 基础设施 | Python 项目、MySQL DDL、FastAPI 健康检查已实现 | 按目标环境核对依赖及账号 |
| M1 销量 | 16888 车型与城市销量已接入，含明细清洗和公司、品牌月度汇总 | 核对目标月行数、缺维情况和汇总结果 |
| M2 行情与财务 | A 股和港股日线、A 股财务、汽车整车指数及期货成本基准有采集代码 | 检查交易日数据覆盖及各数据源稳定性 |
| M3 调度 | 车型月链、城市月链、独立行情任务已有定时与补跑入口 | 核对连续运行日志、失败告警与补跑结果。生产稳定性待验证 |
| M4 Power BI 销量看板 | 仓库已有只读账号配置脚本，报表待建设 | 核对模型关系、销量和市场份额口径 |
| M5 Power BI 关联分析 | 分析方案待实现 | 明确月度对齐、主上市市场及指标边界 |
| M6 发布 | 发布配置与资产待建设 | 确认可公开的数据范围和发布方式 |

优先核对现有调度与数据产出，再建设销量看板和关联分析。数据库操作和补跑入口见 [调度指南](scheduler_guide.md)，月度对齐和指标边界见 [指标口径](metric-definition.md)。
