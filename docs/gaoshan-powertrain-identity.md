# 高山HEV与PHEV独立身份

2026-11-27用户确认区分；[魏牌官网](https://www.wey.com/gaoshan-intelligence.html)同时列出高山8 HEV和插混智慧版，HEV明确无需充电。
16888的2026-10来源：魏牌 高山 `/s/131182/` 364辆（26.58—28.58万元）；魏牌 高山新能源 `/s/129881/` 6103辆。

保留两个独立dim_model ID，现有枚举按HEV→燃油、PHEV→新能源，车型大类均为MPV。
细分HEV/PHEV定义保存于scheduler/gaoshan_identity.py和维度来源凭据，不新增表结构或枚举。
撤销全国与城市的“高山→高山新能源”通用别名，两种当前名称不得再互相规范化。

修复只迁移已存在且ODS明确记为“魏牌 高山新能源”的历史DWD误挂记录，保留行ID、原始名称、月份、销量、厂商品牌、价格和哈希；
同月已有目标记录、来源销量不一致、历史原始名称含义不明均拒绝，不能相加或删除。
城市宽维表分别更新能源分类，独立城市事实不与全国汇总相加。

统一入口：`python -m scheduler.runner --repair-gaoshan-identities logs/etl/gaoshan_identity_receipt.json --plan`。
去掉--plan使用独立ETL账号、仓库锁与同一数据库事务执行并回读，提交后保存回执，不发送消息。
随后用原来源验收版本重验全国2026-10；身份修复本身不代表该月已验收。

复核既有事实时，已批准的其他车型展示别名按同一规则规范业务键，保留原行ID；
不解释未知改名，不合并重复键。高山HEV/PHEV不属于此类别名，必须始终保留为两个业务键。
