# 数据库迁移脚本说明

本目录存放对**已上线**库表结构的增量变更脚本，与 `db/` 下各分层的建表脚本
（`ods/`、`dwd/`、`dws/`、`dim/` 等）区分：建表脚本描述全量结构，本目录只记录
上线后的演进历史。

## 编号约定

- 文件名前缀 `NNN_` 为三位顺序编号，**只增不复用、不重排**。
- 编号与提交顺序一致，新迁移在当前最大编号基础上 +1。
- 迁移由管理员审阅后**手动按编号顺序执行**，应用内 ETL 账号不自动跑迁移
  （部分脚本头部已注明「管理员独立部署 / ETL 不执行本文件」）。

## 关于缺失的 007

现有迁移编号为 001–006、008、009，**不存在 007 文件**（git 历史中也从未提交过
该编号）。在 006 之后的下一次迁移直接使用了 008，007 成为永久空号。

由于无法从代码库考证 007 跳号的确切原因，这里不复用、不补建该编号，以免与任何
可能在其他环境手动执行过的脚本冲突；后续新迁移从 **010** 开始继续递增。
